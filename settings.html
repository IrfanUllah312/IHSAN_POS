Google Sheet Sync

Push your inventory, invoices, and customer dues into a Google Sheet for permanent, off-browser storage.

This is the Apps Script "Web app" URL from the setup steps below — not the sheet's normal share link.

One-time setup (about 2 minutes)

  1. Create or open the Google Sheet you want records saved to.
  2. Go to Extensions → Apps Script.
  3. Delete any starter code, then paste the script below.
  4. Click Deploy → New deployment → choose type Web app.
  5. Set "Execute as" to Me and "Who has access" to Anyone, then click Deploy.
  6. Copy the Web app URL it gives you and paste it into the field above.

Already had this set up before? Re-paste the script below (Deploy → Manage deployments → Edit → New version) — the Customer Dues columns changed.
